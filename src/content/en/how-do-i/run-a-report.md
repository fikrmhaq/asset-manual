## Steps

1. Open **Reports & Audit › Reports**.
2. Choose a report from the cards — each says what it answers.
3. Set the filters you need.
4. Read the table, or the chart beside it.

## Choosing the right one

See [The eight reports](/reports/the-eight-reports) for what each answers. The
common starting points:

| You want | Report |
|---|---|
| A list of everything owned | Inventory |
| A count of what is where | By location |
| What is out on loan right now | Borrowings, with **Past due only** if that is the question |
| Whether the estate is in good repair | By condition |
| Which assets came from which contract | Procurement traceability |

## Filters

Filters differ per report and only ever offer what that report can answer. There
is no department filter and no location filter on any report, because no report
takes one.

Set a classification with the picker, and clear it with **Clear
classification**. Date filters take a start, an end, or both.

## What the report shows

Row reports are paged tables — sort by selecting a column heading, and page
through at the bottom.

Grouped reports show the whole breakdown at once, with totals above and a bar
chart beside the table. Nothing to page through.

## Scope

Every report respects your organization scope. If your roles are limited to one
institution, other institutions' records are not in the figures — so two
colleagues can legitimately get different totals from the same report.

## Exporting the result

**Export CSV** writes what is on screen. Read
[How do I export data?](/how-do-i/export-data) first — for a paged report that
means the current page only.
